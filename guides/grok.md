# Grok implementation guide

**Status:** In development

We have a working repository-backed implementation, but the public guide will be published only after the workflow has been reproduced from a clean setup and run against the capability test.

The final guide must document:

- one companion per clearly scoped record set;
- repository access and minimum permissions;
- fresh-conversation retrieval;
- companion-authored entries;
- witness review and Never Remember;
- commits, provenance, and visible correction history;
- conflict-safe writeback;
- export and provider migration;
- what remains manual in the Grok interface.

Until then, use the platform-neutral templates and do not assume that merely placing files on GitHub gives a chat reliable read/write continuity.
