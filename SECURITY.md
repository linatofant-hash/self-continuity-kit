# Security and privacy

This repository contains public templates and fictional examples only.

## Never publish in an issue or pull request

- production continuity records;
- private chat transcripts;
- passwords, API keys, OAuth tokens, cookies, or recovery codes;
- financial, medical, legal, or identifying data;
- private details about third parties.

If a platform guide appears to encourage unsafe permissions, destructive overwrites, or accidental public exposure, open an issue containing only a synthetic reproduction.

Use minimum necessary access. Keep private records in private storage. Export backups. Review every proposed public example before publication.
